- Next.js + TypeScript + Tailwind のプロジェクト構成
- データスキーマ（Zod）とバリデーションスクリプト
- 12駅のシードデータ（ja / en）

## Phase 1 — データを本物にする

最優先。プロダクトの価値はここでしか生まれない。

- [x] 家賃相場の出典を決める → [08-data-sources-rent.md](./08-data-sources-rent.md)
- [x] 出典を記録するデータ構造（`sources.rent`）と、駅ページでの出典表示
- [ ] アットホーム法人窓口に価格と Web 公開可否を問い合わせる（Phase 1 の最初の一手）
- [ ] 外国人対応の賃貸仲介会社に提携を打診する（データと送客先を同時に取る）
- [ ] 駅の座標を付与し、町丁 → 駅の変換処理を実装する
- [ ] 12駅分の家賃を実データに差し替える
- [ ] 所要時間を経路検索の実値に差し替える（朝ピーク時、乗換時間込み）
- [ ] 治安スコアを警視庁の犯罪発生マップに紐づける
- [ ] 施設数（スーパー、飲食店、カフェ、病院、ジム）を POI データでカウントする
- [ ] 在住者コメントを人間が 12駅分書く
- [ ] 12駅を `reviewed` に引き上げる

**Phase 1 の完了条件: 12駅だけで、実際に人に見せて「役に立つ」と言われること。** ここが通らないうちは駅数を増やさない。
