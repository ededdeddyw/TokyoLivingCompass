# 住む人の層ごとの、1日の過ごし方（試作）

駅ページの点数や本文は「その駅が何に強いか」を伝えます。しかし読み手が本当に知りたいのは、
「自分がここに住んだら、毎日がどうなるか」です。この文書では、住む人を5つの層に分け、
平日と休日の過ごし方を、駅ごとに書けるかを試します。休日は、インドア派とアウトドア派に分けます。

まず大崎と高円寺の2駅で試しました。性格が正反対の2駅で、同じ層の1日がどれくらい変わるかを見るためです。

---

## 1. 書き方の決まり

| 決めたこと | 理由 |
|---|---|
| 1日の流れそのものは**想定**なので、そう明記する | 実在の人の生活ではない。読み手が事実と取り違えないようにします |
| 流れの中に出す数字・店・施設は、すでに持っているデータにあるものだけを使う | 想定の話でも、出てくる店が実在しなければ記事全体が疑われます（ルール35） |
| 地図データ（OpenStreetMap）にしかない店は「地図データ上の」と添える | 人が確かめた店（`groceries`）と、確かめていない店を区別します |
| 性別で分けるのは、夜道と部屋選びのように、実際に判断材料が変わる場面だけにする | 男性・女性で好みを決めつけません |
| 層ごとに「向いている点」と「工夫が要る点」を1行ずつ書く | 過ごし方を読んだあとに、判断へつなげます |

使ったデータ: 通勤時間（`data/computed/commutes.json`）、朝・昼・夜・週末のようす、夜道、
騒音、地形、医療、子育て、確認済みの食料品店（`data/content/ja/`）、
地図データ上の店と公園（`data/computed/pois.json`）です。

## 2. 大崎

### 一人暮らし・男性（20代後半、渋谷の会社に勤める想定）

**平日**
- 8:20 家を出ます。駅とビルは歩行者デッキでつながっているので、雨の日もほとんど濡れずに駅まで行けます。
- 山手線で渋谷まで8分です。乗り換えはありません。
- 19:30 帰り道に、駅のそばのライフ大崎ニューシティ店（23時まで営業）で夕食を買います。
- 20時を過ぎると駅前を歩く人が減り、静かになります。飲みに行くなら、隣の五反田まで出ることになります。

**休日・インドア派**
- 昼まで家で過ごします。まわりのオフィスが休みなので、週末は駅の周りを歩く人が少なく静かです。
- 午後は、週末も営業しているカフェ（地図データ上では Think Park のエクセルシオール カフェ）で本を読みます。

**休日・アウトドア派**
- 朝は、歩いて4分ほどのジム（地図データ上のエニタイムフィットネス）で体を動かします。
- 午後は、湘南新宿ラインで横浜方面へ、りんかい線でお台場方面へ出かけます。どちらも乗り換えはありません。

- 向いている点: 通勤が短く、平日の生活が駅のまわりで終わります。
- 工夫が要る点: 休日に近所で遊べる場所は少なく、出かける先は街の外になります。

### 一人暮らし・女性（30代、品川の会社に勤める想定）

**平日**
- 品川まで3分なので、朝の支度に時間をかけられます。
- 帰りは20時台です。駅前とデッキは夜も明るいですが、退勤の時間を過ぎると人通りが少なくなります。
- 坂を上がった住宅街は、街灯が減ります。部屋を選ぶときは、デッキに近いかどうかと、帰り道の明るさを見ておきたいところです。
- 夕食は、駅とつながるゲートシティ大崎の地下1階にある成城石井で、総菜を買います。

**休日・インドア派**
- 週末は駅の周りを歩く人が少なく、家で静かに過ごせます。
- ただし山手通り（片側2車線の大通り）に面した部屋では、車の音が一日中続きます。

**休日・アウトドア派**
- 服や雑貨の買い物は、渋谷（8分）や新宿（13分）へ出ます。大崎の駅前には、買い物を目当てに歩ける店は多くありません。

- 向いている点: 通勤の短さと、週末の静けさです。
- 工夫が要る点: 夜に駅前の人通りが少なくなることを、安心と取るか不安と取るかで評価が変わります。

### DINKs（共働きの夫婦。勤め先は渋谷と大手町の想定）

**平日**
- 1人は渋谷まで8分です。もう1人は大手町まで25分かかり、途中で1回乗り換えます。
- 帰りの早いほうが、ライフで食材を買います。
- 外食はビルの中の店が中心で、20時を過ぎると選べる店が減ります。

**休日・インドア派**
- 家で料理をします。普段の食材はライフ、少し良いものは成城石井で、と使い分けます。

**休日・アウトドア派**
- 湘南新宿ラインで横浜方面へ、埼京線で埼玉方面へ、乗り換えずに日帰りで出かけます。

- 向いている点: 2人の勤め先が別の方向でも、どちらも通いやすい立地です。
- 工夫が要る点: 休日を近所の店めぐりで過ごしたい夫婦には、店の数が物足りません。

### 子育てファミリー（共働き、保育園に通う子どもが1人の想定）

**平日**
- 朝、保育園に子どもを送ってから出勤します。保育園の空き状況は、品川区のページで住所ごとに確かめておきます。
- 駅前は歩道が広く、ベビーカーで動きやすいです。ただし坂の上の住宅地からは、上り下りがあります。
- 夕方、ライフで食材を買って帰ります。

**休日・インドア派**
- 週末も開いているゲートシティ大崎の商業区画で、雨の日の買い物を済ませます。

**休日・アウトドア派**
- 歩いて5分ほどの小さな公園（地図データ上のひふみ公園、大崎西口公園など）で遊びます。
- 広い公園で遊ぶなら、しながわ中央公園まで歩いて18分ほどかかります。

- 向いている点: 親の通勤が短く、駅前はベビーカーで動きやすいです。
- 工夫が要る点: 食料品をどこで買うかと、広い公園までの距離です。

### シニア世代（退職した夫婦の想定）

**平日**
- 通勤はありません。昼どきは周りの会社員で飲食店が混むので、外食や買い物は午前か、14時以降に出ます。
- 心臓病を専門にする大崎病院 東京ハートセンターが、南改札から歩いて8分ほどです。
- 総合病院のNTT東日本関東病院は、五反田駅の近くにあります。

**休日・インドア派**
- 週末は周りが静かで、家でゆっくり過ごせます。

**休日・アウトドア派**
- 小さな公園を回りながら散歩をします。住宅地は坂の上にあることが多く、坂を負担に感じる人もいます。

- 向いている点: 週末の静けさと、どこへでも乗り換えなしで行ける便利さです。
- 工夫が要る点: 駅のそばの病院は診る分野が限られ、日々の買い物ができる店も少なめです。

## 3. 高円寺

### 一人暮らし・男性（20代後半、新宿の会社に勤める想定）

**平日**
- 中央線快速で新宿まで8分です。朝の混雑率は158%で、遅れもよく出るため、早めに家を出ます。
- 帰りは、南口のガード下の飲み屋に寄ることがあります。終電のあとも、駅のまわりには人通りがあります。
- 夜遅くの買い物は、地図データ上では深夜1時まで営業している東急ストア 高円寺店で済ませます。

**休日・インドア派**
- 午前中の商店街は意外に静かです。古着店やカフェが開くのは昼前後です。
- 家の近くのカフェで過ごします。駅から歩いて1分ほどの範囲にも、カフェがいくつもあります。

**休日・アウトドア派**
- 古着店やライブハウスをめぐります。週末は、古着を目当てに来た人で商店街が混みます。
- 土休日は快速が止まらないので、各駅停車で出かけます。

- 向いている点: 新宿に近く、家賃を抑えながら、外食と夜の店に困りません。
- 工夫が要る点: 朝の中央線の混雑と遅れ、それに部屋によっては夜の人の声です。

### 一人暮らし・女性（30代、東京駅近くの会社に勤める想定）

**平日**
- 中央線快速で東京まで24分です。乗り換えはありません。
- 商店街の通りは深夜まで明るく、人通りがあるので、夜道の不安は小さいです。
- 一本入った木造住宅街は道が細く、街灯も多くありません。帰り道が飲み屋街を通るかどうかで、部屋を選び分けたいところです。

**休日・インドア派**
- 家で過ごします。南口のガード下に近い部屋では、深夜まで人の声が届きます。

**休日・アウトドア派**
- 平坦な台地の上にあるので、自転車で中野や阿佐ヶ谷まで出かけます。

- 向いている点: 夜遅くても人通りのある道を選んで帰れます。
- 工夫が要る点: 部屋の場所によって、夜の音と道の暗さが大きく変わります。

### DINKs（共働きの夫婦。勤め先は新宿と渋谷の想定）

**平日**
- 1人は新宿まで8分です。もう1人は渋谷まで18分かかり、途中で1回乗り換えます。
- 夕食は外で済ませることが多くなります。夜遅くまで営業している飲食店が多いので、帰りが遅くても店に困りません。

**休日・インドア派**
- 週末に、地図データ上のオーケーストア 高円寺店（21時半まで）で食材をまとめて買い、家で料理をします。

**休日・アウトドア派**
- 夏は阿波おどりを見に行きます。その時期は数日のあいだ、商店街での買い物がしにくくなります。

- 向いている点: 外食できる店が多く、2人の帰りが遅くても食事に困りません。
- 工夫が要る点: 築浅で設備の整った2人向けの部屋は、見つけるのに時間がかかります。

### 子育てファミリー（共働き、保育園に通う子どもが1人の想定）

**平日**
- 朝、保育園に子どもを送ってから出勤します。保育園の空き状況は、杉並区のページで住所ごとに確かめておきます。
- 台地の上で平坦なので、ベビーカーでの移動は楽です。
- 夕方は、駅の近くのスーパーで買い物を済ませます。歩いて3分ほどの範囲に、スーパーがいくつもあります。

**休日・インドア派**
- 家で過ごします。駅の近くに、子ども向けの屋内施設があるかどうかは、データでは確かめられていません。

**休日・アウトドア派**
- 歩いて4分ほどの小さな公園（地図データ上の高円寺中央公園など）で遊びます。
- 大きな公園の和田堀公園や善福寺川緑地までは、距離があります。

- 向いている点: 平坦で、買い物と病院が歩いて行ける範囲にそろっています。
- 工夫が要る点: 子育て世帯は少なく、店や住宅は単身者向けが中心です。夜遅くまで人通りがあります。

### シニア世代（退職した夫婦の想定）

**平日**
- 通勤はありません。歩いて行ける範囲に、クリニックが25件、薬局が23件あります。
- 入院もできる北條病院まで、歩いて7分ほどです。
- 商店街で、毎日の買い物が終わります。

**休日・インドア派**
- 家で過ごします。週末は来街者で商店街が混むので、買い物は平日に済ませます。

**休日・アウトドア派**
- 平坦なので、近所の散歩が苦になりません。

- 向いている点: 病院と買い物が歩いて行ける範囲にあり、坂も少ないです。
- 工夫が要る点: 夜遅くまで人の声が聞こえる環境が合うかどうかです。

## 4. 2駅を並べて分かったこと

- 同じ層でも、駅によって1日の流れがはっきり変わります。大崎は「平日は便利、休日は街の外へ出る」、
  高円寺は「平日の朝は混む、夜と休日は近所で過ごせる」という違いが、どの層にも出ます。
- インドア派とアウトドア派の違いは、平日より休日に出ます。平日は通勤で1日の形が決まるため、分けるのは休日だけで足ります。
- 性別で変わったのは、夜道と部屋の選び方だけでした。それ以外は、男性と女性で同じ文になりました。
- **データが足りずに書けなかったもの**: 子ども向けの屋内施設、図書館、ドラッグストア、
  シニア向けの集まりの場、スポーツ施設の種類です。とくにドラッグストアと図書館は、
  どの層の1日にも出てくるので、地図データから取りたいと考えています。

## 5. サイトの構成をどう変えるか（案）

いまの区分（[14-audience-segments.md](./14-audience-segments.md)）は、
「子どもの有無」「夜の過ごし方」「家賃と立地のどちらを優先するか」の3軸で、8区分になっています。
今回の層は、これを読み手が自分を見つけやすい形に言い換えたものになります。

| 今回の層 | いまの3軸での位置 |
|---|---|
| 一人暮らし（男性・女性） | 子どもなし。夜の過ごし方と家賃の軸は人による |
| DINKs | 子どもなし。立地を優先することが多い |
| 子育てファミリー | 子どもあり |
| シニア世代 | **いまの3軸には無い**。医療・坂の少なさ・日々の買い物を重く見る層 |
| インドア派 / アウトドア派 | 「夜の過ごし方」に近いが、休日の過ごし方まで含む |

進め方の案:

1. 入口を「あなたはどの層ですか」（5つ）と「休日はインドア派かアウトドア派か」（2つ）にする。
   いまの3軸の切り替えは、細かく調べたい人向けに残します。
2. シニア世代の重みを新しく決めます（医療機関、平坦さ、スーパーの近さ、静かさ）。
3. 駅ページに「この層の人が住んだら」の欄を作り、選んだ層の1日の過ごし方と、向いている点・工夫が要る点を出します。
4. 458駅 × 5層 × 3場面は、人の手では書けない量です。データから下書きを作り、
   人が書いた駅（いま33駅）から順に読み直して出します。下書きには、使ったデータが無い場面を書きません。

決めてほしいこと:
- 層は5つでよいか（たとえば「学生」「単身赴任」を足すか）
- 一人暮らしを男性と女性に分けるか。今回の試作では、違いが夜道と部屋選びだけでした。
  分けずに「夜道」の欄を全員に出す方法もあります
- 1日の過ごし方を、いまのように**想定と明記したうえで**駅ページに出してよいか

## 6. 層と休日の過ごし方ごとの点数（試作）

利用者から、層ごと・インドア派とアウトドア派ごとに、その駅に住む向き不向きを点数で出したいという要望がありました。
その際、点数は駅のまわりだけで完結させません。**電車で行きやすい駅まで含めて**見ます。
大崎のまわりに広い公園は少ないですが、電車に乗れば浜離宮恩賜庭園やお台場の公園まで十数分で行けます。
そのためアウトドア派でも休日を楽しめる、という見方です。

計算は `scripts/build-lifestyle-scores.py`、結果は `data/computed/lifestyle.json` にあります。

### 6.1 点数の分け方

点数は「暮らし」と「楽しみ」の2つから作ります。

| 部分 | 何を見るか | どこまで含めるか |
|---|---|---|
| 暮らし | 層ごとに違います（下の表） | 駅のまわりだけです。毎日のことなので、電車に乗らないと済まないものは数えません |
| 楽しみ（アウトドア派） | 広い公園（1ha以上）の広さと、ジムの多さです | 近所の広い公園と、電車で行ける駅の広い公園を半々で見ます |
| 楽しみ（インドア派） | 家の静かさと、外食・カフェ・買い物の店の多さです | 静かさは駅のまわりで見ます。店の多さは、電車で行ける駅まで含めて見ます |

電車で行ける駅は、所要時間で割り引きます。0分なら割り引かず、45分で魅力を0として数えます。
所要時間は、通勤時間と同じ鉄道網で、全458駅どうしについて出しています。

| 層 | 暮らしで見るもの | 楽しみの比重 |
|---|---|---|
| 一人暮らし | 通勤、一人暮らし適性、治安、買い物、家賃の安さ | 4割 |
| DINKs | 通勤、乗換利便性、治安、飲食店、買い物、病院 | 4割 |
| 子育てファミリー | ファミリー適性、治安、買い物、病院、浸水想定、静かさ、通勤 | 3割 |
| シニア世代 | 病院、買い物、静かさ、治安、浸水想定、坂の少なさ | 3割 |

子育て世帯とシニア世代は、毎日のことの比重が大きいので、楽しみを3割にしました。
シニア世代は、いまの区分（[14-audience-segments.md](./14-audience-segments.md)）に無かった層です。
病院と坂の少なさを、新しく重く見ています。

### 6.2 広い公園の面積の出どころ

これまでの「公園・自然」の点は、小さな公園も含めた公園の**数**で出していました。
そのため、葛西臨海公園駅は2点、新宿御苑前駅は35点と低く出ていました。
アウトドア派の行き先を測るには、公園の**広さ**が要ります。

- 国土数値情報の都市公園データ（P13、平成23年度）: 東京都の公園6,390か所の、名前・面積・位置があります。
- 上のデータに入っていない海上公園（お台場海浜公園、潮風公園など）と国民公園（新宿御苑、皇居外苑など）は、OpenStreetMap から形を取り、面積を計算しました。新宿御苑は57.4haと出ました。環境省の公表値58.3haと、ほぼ合っています。

都市公園データは2011年時点のものです。そのあとにできた公園は入っていません。

### 6.3 大崎と高円寺の結果

点数は、23区の駅どうしの相対的な位置を5点満点にしたものです。

| 層 | 大崎・インドア派 | 大崎・アウトドア派 | 高円寺・インドア派 | 高円寺・アウトドア派 |
|---|---|---|---|---|
| 一人暮らし | 3.5 | 2.0 | 5.0 | 4.0 |
| DINKs | 4.5 | 3.0 | 4.5 | 4.0 |
| 子育てファミリー | 2.0 | 1.5 | 3.5 | 3.0 |
| シニア世代 | 2.0 | 1.0 | 5.0 | 4.5 |

電車で行きやすい行き先も、あわせて出せます。

### 6.5 気になっている点

- アウトドア派の上位に、皇居や上野公園に近い都心の駅が並びます。歩いて行ける広い公園があり、通勤も短いからです。
  ただし、その駅の家賃で暮らせる人は限られます。家賃の安さは、一人暮らしの「暮らし」に1割しか入っていません。
- 所要時間は電車に乗っている時間だけで、駅から公園までの徒歩は入っていません。
- 公園の広さだけを見ており、川沿いの遊歩道、海辺、山や郊外への出やすさ（奥多摩・湘南など）は入っていません。
- インドア派の「屋内で楽しめる場所」は、外食・カフェ・買い物の店の数で代わりに測っています。映画館・図書館・書店は入っていません。
