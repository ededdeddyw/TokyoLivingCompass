# 画面の見た目の決まりごと

駅ページは、文章の深さでは既存のまとめ記事に勝てるようになってきたが、見た目は
文字が続くだけで、どこに何があるかが分かりにくかった。2026-10 に見た目を作り直した。
この文書には、そのとき決めた色・部品・並べ方と、その理由をまとめる。

---

## 1. サイトに持たせる印象と色

| 持たせたい印象 | 理由 |
|---|---|
| 正直で、事実に基づく | 都合の悪い事実も書き、出典を示すサイトなので、信頼が何より大切 |
| 明るく、前向き | 住む街を選ぶのは新しい暮らしを始める場面。不動産屋の重さより街歩きの軽さを出す |
| 迷わせない | 名前のとおり方角を示す。色で判断の手がかりを出すが、色に頼りすぎない |

ここから次の色を選んだ（`src/app/globals.css` の `@theme`）。

| 役割 | 色 | 使う場所 |
|---|---|---|
| 主役 | 水色〜青緑（`accent` `accent-strong` `accent-bright`） | 見出しの帯、リンク、選んでいる状態、アイコン |
| 差し色 | あたたかいオレンジ（`sun`） | 強みの印、「どんな街か」、一言の左の線、総合評価のカード。画面の1割以下に抑える |
| 点数のよい側 | 深い青緑（`good`） | ◎・強み・向いている人 |
| 点数の悪い側 | コーラル（`bad`） | ×・弱み・向かない人 |

差し色のオレンジと点数の悪い側の色を分けたのは、オレンジが「警告」と読まれないようにするためである。
点数の良し悪しは、色だけでなく ◎○△× の記号とアイコンも必ず添える。赤と緑を見分けにくい人がいる。

飲食店・カフェ・ナイトライフは、多いほうがよいかどうかが人によって違う（`CLAUDE.md` ルール40）。
良し悪しの色を付けず、中立の色の棒で出し、強み・弱みの一覧にも入れない（`PREFERENCE_AXES`）。

## 2. 駅ページの並べ方

参考にしたのは、点数に一言の言葉を添える Walk Score と、最上部に分野ごとの成績を並べる
Niche・AreaVibes（英語圏の街の評価サイト）である。**一番上の画面で、この駅の強みと弱みが分かる**ようにし、
詳しい本文は下で読む作りにした。

1. 駅名の帯（区・路線・一言・性格タグ・駅の写真）
2. 要点のカード（家賃の目安・いちばん近いオフィス街・使える路線・総合評価）
3. 目次（画面の上に固定。スマホでは横にスクロールする）
4. 要約の本文
5. どんな街か
6. 家賃（帯と平均を1枚のカードに。以前は同じ出典の数字を2つの節に出していた。区の駅の平均・23区の駅の平均と比べて、高いか安いかを添える）
7. 通勤（短い順の横棒。乗り換えの有無をアイコンで）
8. 評価（強み3つ・弱み3つを先に。18軸は畳んで「すべて見る」。どの軸にも、何を問うているかの一文を添える）
9. 向いている人・向かない人
10. 住むと分かること（アイコン付きのカード。一言を見せ、長い本文は「続きを読む」で畳む。子育てと災害のカードには、駅のまわりにかかる区の公式ページへのリンクを置く）
11. 比べる（近くの駅・迷いやすい駅）

本文を畳んでも HTML には残るので、検索にも読み上げにも届く。

## 4. 利用者の確認で直したこと（2026-10-12）

| 指摘 | 直したこと |
|---|---|
| 軸の名前だけでは、何を測っているのか分からない | 軸ごとに問いの一文を添えた（`dict.axisQuestions`）。問いは、実際に測っている中身を超えない言い方にする |
| 駅の様子が写真で分からない | Wikimedia Commons の写真のうち、CC0・パブリックドメイン・CC BY・CC BY-SA のものだけを使う。作者とライセンスを写真の下に必ず出す（`data/computed/station-photos.json`） |
| 朝・昼・夜・週末のカードが、改行が多くて読みにくい | 半分の幅のカードの中でさらに2列にしていたので、1行が10字ほどで折り返していた。横幅いっぱいの1列にし、見出しを左、本文を右に置いた |
| 保育園・学区・ハザードマップは区ごとに違う | 駅から500m以内に代表点がある町丁目の区を集め（`scripts/build-station-wards.py`）、区ごとの公式ページへリンクする。区の境の駅は、すべての区を並べる |
| 家賃が高いのか安いのか分からない | 同じ区の駅の平均と、23区の駅の平均を並べる。駅を1つずつ同じ重みで平均しているので「区の家賃相場」とは書かず「区の駅の平均」と書く |
| 治安の点が、体感より低い | 総数（自転車盗や万引きを含む）と、順位で点にする方法をやめた。粗暴犯・凶悪犯・侵入窃盗を、23区の駅の中央値との比で点にする（`docs/03-scoring.md`） |
